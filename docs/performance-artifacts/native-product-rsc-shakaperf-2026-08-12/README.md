# Native product RSC ShakaPerf evidence (2026-08-12)

This is the first native `Products/Discover/Show` comparison in this repository
generated by the actual `shaka-perf` CLI. The control is pinned before the
native RSC work; the experiment uses the same deterministic database seed and
adds `rsc=1` to select the streamed React on Rails RSC response.

Read [`summary.json`](./summary.json) first. It records the exact revisions,
command, pages, estimator values, p-values, visual/accessibility checks, exit
status, and the bounded conclusion. The `raw/` directory preserves the CLI's
assembled report plus each product's statistical, visual, and accessibility
JSON.

The generated interactive reports remain in the ignored local
`compare-results/` directory:

- `compare-results/full-report.html`
- `compare-results/self-contained-performance-report.html`
- `compare-results/full-report.zip`

The command completed all five stages and generated the reports, then exited
nonzero with `FAILED: 2 perf regressions`. That matters: RSC is substantially
better for paint/LCP/Lighthouse score in this run, but worse for TTFB and
transferred bytes, with an additional Microsoft TBT regression. Do not describe
this artifact as proof that RSC is unconditionally better.
